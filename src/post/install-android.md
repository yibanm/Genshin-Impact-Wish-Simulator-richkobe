# 在 <span>Android</span> 上使用

## 安装

从 Release 页下载 `genshin-wish-roll-richkobe-<版本>-android-arm64.apk`，在手机上打开安装。

1. 下载完成后点通知栏或文件管理器里的 APK。
2. 系统会提示「禁止安装未知应用」——点「允许此来源」再装（这是安卓对所有非商店应用的统一提示，不是本应用的问题）。
3. 安装完从桌面图标启动。应用固定横屏运行，画面会铺满整块屏幕（含挖孔区）。

覆盖安装新版本时直接装新 APK 即可，**名单与祈愿记录会保留**（同一签名密钥）。

## 第一次打开

- 开屏弹窗里有「使用教程」入口与更新公告；勾「不再提示」后下次启动不再弹。
- 主界面右上角是卡池页签：角色活动 / 武器 / 常驻 / 群星点名，横向可滑动。
- 点名功能在「群星点名」页签：先建名单（手动添加、批量添加或导入 TXT），勾上启用后即可抽。

## 导入名单

1. 主界面齿轮 → 群星点名 → 「导入 TXT」。
2. 选一个一人一行的文本文件；行尾加空格和数字可指定星级（如 `张三 5` = 五星）。
3. 编码自动识别 UTF-8 与 GBK（Windows 记事本存的 ANSI 也能读）。

## 备份与迁移

- 齿轮 → 备份：导出会唤起系统分享面板，可存到文件、发微信或传电脑。
- 安卓与 Windows 的数据不互通（各存本机），迁移用导出/导入。
- 卸载应用会一并清除本地数据，需要保留请先导出。
