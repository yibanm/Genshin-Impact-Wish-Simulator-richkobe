# 在 <span>Android</span> 上使用

## 本项目不提供安卓安装包

本项目只发布 **Windows 桌面版**（安装版 + 便携版）与 **Web 静态站**，没有 APK。
安卓设备可以用「Web 静态站 + 添加到主屏幕」的方式使用，体验接近原生应用。

## 前提

Web 静态站需要先部署到一个可访问的地址——本项目是纯静态站点，任何静态托管都可以：

1. 把 `*-web.zip` 解压；
2. 部署到任意静态托管服务（GitHub Pages、Cloudflare Pages、Netlify，或自己的服务器）；
3. 记下部署后的网址。

> 注意：手机浏览器**不能**直接打开解压出来的 `index.html`，应用使用根路径引用资源，本地文件协议下会全部 404。必须通过 HTTP(S) 访问。

## 添加到主屏幕

1. 用安卓浏览器打开上面的网址（Chrome、Edge、Brave 等 Chromium 内核浏览器都支持）。
2. 等页面加载完成。
3. 点浏览器菜单（右上角三个点）→「添加到主屏幕」/「安装应用」。
4. 确认后桌面会出现图标，点开即全屏运行，看起来和普通 App 一致。

## 离线使用

添加到主屏幕后，应用会缓存自身资源，**断网也能打开**（前提是已完整加载过一次）。

## 数据说明

- 祈愿记录、名单配置、导入的姓名与图标都存在**浏览器本地**，不上传任何服务器。
- 清除浏览器数据会导致记录丢失，需要保留请先在「备份」页导出。
- 安卓桌面版与 Windows 桌面版的数据**不互通**（各自存在本地），如需迁移请用「备份/恢复」功能导出再导入。
