# 在 <span>Windows</span> 上使用

## 安装

从 Release 页下载两种形态之一，功能完全一致，都可**完全离线**运行（不联网、无广告、无统计上报）：

| 形态 | 文件 | 适用场景 |
|---|---|---|
| 安装版 | `genshin-wish-roll-richkobe-<版本>-windows-x64-setup.exe` | 要开始菜单图标、双击即用 |
| 便携版 | `genshin-wish-roll-richkobe-<版本>-windows-x64-portable.zip` | 不写注册表，解压即用、可放 U 盘 |

1. 安装版：双击 exe 按向导装；程序未做代码签名，SmartScreen 可能拦一次，点「更多信息」→「仍要运行」。
2. 便携版：解压 zip 到任意目录（路径含中文或空格都可以），双击里面的 exe 运行。
3. 卸载：安装版走系统「设置 → 应用」；便携版删除解压目录即可。

## 第一次打开

- 开屏弹窗里有「使用教程」入口与更新公告；勾「不再提示」后下次启动不再弹。
- 主界面右上角是卡池页签：角色活动 / 武器 / 常驻 / 群星点名，页签多了会出横向滚动条。
- 右上角 X 关闭程序；齿轮进设置与名单管理。

## 点名功能

1. 齿轮 → 群星点名 → 「新建名单」或「导入 TXT」。
2. 名单里可加名字、指定星级（3/4/5 或随机）、换头像图。
3. 勾选启用后，回主界面切到「群星点名」页签即可抽人；一轮内不重复，抽完可重置。
4. TXT 一人一行；行尾加空格和数字指定星级（如 `张三 5` = 五星）。UTF-8 与 GBK 编码都支持。

## 备份与迁移

- 齿轮 → 备份：导出成文件，换电脑时导入即可带走全部记录与名单。
- 数据存在本机用户目录，**不上传任何服务器**。
