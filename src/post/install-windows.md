# 在 <span>Windows</span> 上安装

## 两种使用方式

本项目提供 Windows 桌面版与 Web 静态站两种形态，按需选择：

| 形态 | 文件 | 适用场景 |
|---|---|---|
| 安装版 | `*-windows-x64-setup.exe` | 想要开始菜单图标、开机即用 |
| 便携版 | `*-windows-x64-portable.zip` | 不想写注册表，解压即用、可放 U 盘 |

两者功能完全一致，都可**完全离线**运行（不联网、无广告、无统计上报）。

## 安装版

1. 双击 `*-windows-x64-setup.exe`，按向导完成安装。
2. 程序未做代码签名，Windows SmartScreen 可能拦一次：点「更多信息」→「仍要运行」即可。
3. 安装后从开始菜单或桌面快捷方式启动。
4. 卸载：设置 → 应用 → 找到「原神抽卡点名器」→ 卸载。

## 便携版

1. 把 `*-windows-x64-portable.zip` 解压到任意目录（路径含中文或空格都可以）。
2. 双击解压出的 `原神抽卡点名器.exe` 直接运行。
3. 卸载：删除整个解压目录即可。

## 数据存放位置

- 祈愿记录、名单配置、导入的姓名与图标：存在应用自己的本地存储里，**不上传任何服务器**。
- 便携版的数据跟随解压目录所在的用户配置；安装版数据在系统用户目录下。
- 卸载前如需保留记录，先在应用内「备份」页导出。

## 浏览器直接使用（不装桌面版）

把 `*-web.zip` 解压后用任意静态服务器托管即可（**不能直接双击 `index.html`**，应用使用根路径引用资源，本地文件协议下会 404）。也可以把它部署到任意静态托管服务。

浏览器要求：Chromium 内核（Chrome、Edge、Brave 等）或 Firefox、Safari 的近年版本。
